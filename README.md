# Computer Vision Project 2

Classical computer-vision solutions for Questions 1–4 are in `q1/` through `q4/`. The combined notebook is `CV_Project2_Q1-Q4.ipynb`.

Set up the environment and run scripts from the repository root:

```bash
uv sync
uv run python q1/solve.py
uv run python q2/solve.py
uv run python q3/solve.py
uv run python q4/solve.py
```

Generated figures and results are written to `outputs/qN/`.

[Open the notebook in Google Colab](https://colab.research.google.com/github/gpu004/cv-project2/blob/main/CV_Project2_Q1-Q4.ipynb)
